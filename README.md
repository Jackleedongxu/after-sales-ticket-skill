# 售后工单结构化 Skill

将口语化、非正式的售后工单描述转换为标准 JSON 卡片。

适用于食品加工设备（UHT 杀菌机、巴氏杀菌机等）售后工程师的口述记录、语音转写内容、信息不完整或带有闲聊的工单场景。

## 功能特点

- 严格按固定字段输出标准 JSON
- 缺失信息统一标记为 `[N/A]`，不臆造内容
- 如实保留原文中的矛盾信息
- 自动忽略天气、路况、闲聊等无关内容
- 支持一次输入包含多个现场时分别输出多张卡片

## 输出字段

| 字段       | 说明                     |
|------------|--------------------------|
| 适用机型   | 设备型号                 |
| 故障代码   | 报警或故障代码           |
| 故障现象   | 主要症状描述             |
| 可能原因   | 原文明确指向的原因       |
| 排查步骤   | 现场实际检查过程         |
| 所需配件   | 更换的配件及型号         |
| 解决方案   | 最终处理措施及效果       |
| 注意事项   | 对客户的提醒或后续建议   |
| 客户/现场  | 工厂类型或名称           |
| 其他信息   | 其他相关记录             |

## 使用示例

**输入**：

> 又去了一个客户，好像是乳品厂，设备是巴氏杀菌机。客户说流量不稳定，时大时小，报警了好几次。我看了看压力表，感觉进口压力有点低。后来发现过滤器堵了，拆下来洗了洗就好了。配件没换，就是清洗了一下。客户说这个过滤器以前也堵过。

**输出**：

```json
{
  "适用机型": "巴氏杀菌机",
  "故障代码": "[N/A]",
  "故障现象": "流量不稳定，时大时小，多次报警",
  "可能原因": "过滤器堵塞；进口压力偏低",
  "排查步骤": "查看压力表，发现进口压力偏低，随后检查过滤器并确认堵塞",
  "所需配件": "[N/A]（未更换配件，仅清洗过滤器）",
  "解决方案": "拆下过滤器清洗后恢复正常",
  "注意事项": "该过滤器此前也发生过堵塞",
  "客户/现场": "乳品厂",
  "其他信息": "[N/A]"
}
```

## 文件说明

- `SKILL.md`：标准 Agent Skill 定义文件，包含完整规则与处理逻辑。
- `scripts/format_ticket.py`：辅助脚本，可用于校验输出 JSON 格式或作为参考实现。
- 本目录可直接作为公开 Skill 仓库使用，也可集成到支持 Agent Skills 的工具中。

## 设计原则

1. 忠实原文，禁止臆造
2. 信息缺失时明确标注 `[N/A]`
3. 矛盾信息如实记录
4. 忽略无关闲聊
5. 多现场独立输出
